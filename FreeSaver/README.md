# FreeSaver — бесплатный загрузчик видео (Android APK)

Приложение скачивает видео/аудио по ссылке в выбранном качестве
(лучшее, 1080p, 720p, 480p, 360p, MP3). Работает на движке yt-dlp
(TikTok, YouTube, Instagram, VK, Twitter/X и ещё 1000+ сайтов).
Файлы сохраняются в папку «Загрузки/FreeSaver». Android 10 и новее.

## Способ 1. Собрать APK бесплатно, ничего не устанавливая на компьютер (рекомендую)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите **New repository**, назовите его `FreeSaver`, создайте.
3. Распакуйте этот архив. В репозитории нажмите **Add file → Upload files**
   и перетащите ВСЁ содержимое папки FreeSaver
   (включая скрытую папку `.github`. Если браузер её не берёт —
   создайте файл через **Add file → Create new file** с именем
   `.github/workflows/build.yml` и вставьте туда содержимое из архива).
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка запустится сама (3–8 минут).
   Если нет — выберите «Build APK» → **Run workflow**.
6. Когда появится зелёная галочка, откройте сборку и внизу в разделе
   **Artifacts** скачайте `FreeSaver-apk`. Внутри zip — файл `app-debug.apk`.
7. Перекиньте APK на телефон, откройте, разрешите
   «Установку из неизвестных источников». Готово.

## Способ 2. Через Android Studio

1. Установите Android Studio (бесплатно) с https://developer.android.com/studio
2. File → Open → выберите папку FreeSaver. Дождитесь Gradle Sync.
3. Build → Build Bundle(s)/APK(s) → Build APK(s).
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Как пользоваться

- Скопируйте ссылку на видео, вставьте в поле, выберите качество, «Скачать».
- Или в TikTok/YouTube нажмите «Поделиться» → FreeSaver — ссылка вставится сама.
- Если перестало качать (YouTube часто меняет защиту) — нажмите
  «Обновить движок». Это решает 90% проблем.

## Если сборка падает

- Ошибка на зависимости `youtubedl-android`: в `app/build.gradle.kts`
  замените версию `0.17.2` на последнюю с
  https://github.com/yausername/youtubedl-android (раздел Releases).
- Приложение сразу вылетает на телефоне: проверьте, что Android 10+.

## Важно (юридически)

- Скачивайте только своё содержимое или то, что разрешено автором/лицензией.
  Скачивание с YouTube и TikTok нарушает их условия использования,
  а чужой контент защищён авторским правом.
- В Google Play такое приложение не пропустят. Распространяйте APK
  со своего сайта или Telegram-канала и указывайте это ограничение
  в описании.

## Ваши следующие шаги по улучшению

- Свой значок (папка `res/mipmap`) и название в `AndroidManifest.xml`.
- Смена `applicationId`/`namespace` (`com.example.freesaver`) на свой.
- Тёмная тема, история загрузок, очередь — добавляются в `MainActivity.kt`.
